## Установка

### Автоматическая установка (Windows)
1. Распакуйте архив с озвучкой.  
2. Откройте файл `Install Windows.bat`
4. Готово! Озвучка установлена и готова к использованию.

### Ручная установка

#### Windows
1. Перейдите в папку с установленной игрой (обычно `C:\Program Files (x86)\Steam\steamapps\common\Altushka dlya skufa`).  
2. Откройте папку `game`.  
3. Скопируйте папку `another_attempt` в папку `game`.  
4. Готово! Озвучка установлена и готова к использованию.

#### Linux
1. Найдите папку с установленной игрой в вашей Steam-библиотеке.  
2. Откройте папку `game`.  
3. Скопируйте папку `another_attempt` в папку `game`.  
4. Готово! Озвучка установлена и готова к использованию.


### Примечания

- Убедитесь, что вы скопировали **именно папку `another_attempt`** в папку `game`.  
- Если игра была открыта во время установки, перезапустите её для корректного применения озвучки.
